# Записи фільмів

Програма, яка дозволяє додавати записи про фільми у текстовий файл через консоль

## Запуск
### Додати запис:
python cli.py add "Test 3" 1991 "scifi" 2,34,12 3 "Max Payne"
### Подивитися існуючі записи:
python cli.py list
### Відфільтрувати записи по категорії фільму:
python cli.py find horror
### Повернути кількість фільмів по категоріям:
python cli.py report

## Формат даних
data.txt, один запис на рядок: Ім'я фільму;рік;категорія;довжина фільму (годин:хвилин:секунд);рейтинг;список акторів
